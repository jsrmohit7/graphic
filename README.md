# Mona Rani — Graphic Designer Portfolio

A brutalist, high-craft editorial portfolio designed for **Mona Rani** (Graphic Designer & Visual Communications Lead, Ranchi).

Inspired by the [Vexoo](https://vexoo.framer.website/) Framer design system.

---

## 🎨 Features & Highlights
- **Kinetic Hero Title**: Brutalist dynamic typography switcher (`MONA RANI`) with responsive hover skew transitions.
- **Interactive Navigation Bento**: Frosted glass cards with animated $-45^\circ$ arrow rotation.
- **Software Stack Marquee**: Continuous infinite ticker featuring Photoshop (`Ps`), Illustrator (`Ai`), CorelDRAW (`Cd`), After Effects (`Ae`), Figma (`Fg`), and InDesign (`Id`).
- **Live Local Clock**: Real-time Ranchi, India clock (`Asia/Kolkata` IST) with pulsing status beacon.
- **Theme Switcher**: Dark & Light theme modes with smooth transitions and `localStorage` persistence.
- **Projects Showcase**: High-resolution gallery with category filters (Branding, Posters, Social Media, Illustration) and interactive Lightbox modal.
- **Interactive Contact Form**: Project type and budget selection pills with toast feedback.
- **Resume Integration**: Direct PDF download/view for `Mona_Rani_Resume.pdf`.
